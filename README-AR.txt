تطبيق دروس احترافية دوت نت - مشروع أندرويد

مهم: هذا مشروع Android Studio قابل للبناء، وليس ملف APK جاهزًا للتثبيت بعد.

طريقة استخراج APK على الكمبيوتر:
1) ثبّت Android Studio وافتحه.
2) اختر Open ثم حدد مجلد DrossPCNet بعد فك الضغط.
3) انتظر اكتمال Gradle Sync وتنزيل مكونات Android المطلوبة.
4) من القائمة Build اختر Build Bundle(s) / APK(s) ثم Build APK(s).
5) بعد نجاح البناء اضغط Locate للوصول إلى app-debug.apk.

خصائص النسخة:
- تفتح مدونة https://drosspcnet.blogspot.com/?m=1 داخل التطبيق.
- أي موضوع جديد يظهر من الموقع تلقائيًا دون إعادة بناء التطبيق.
- اتصال إنترنت مطلوب.
- زر الرجوع يعود للصفحة السابقة داخل المدونة.
- أيقونة التطبيق مأخوذة من الشعار المرفق.

ملاحظة: لم يتم اختبار المشروع على جهاز أندرويد فعلي أو إصدار APK في هذه البيئة لعدم توفر Android SDK وGradle هنا.
